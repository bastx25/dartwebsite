# Steeldarts Doppel Open - Landjugend Lasberg

Statische One-Page-Eventseite für Cloudflare Pages.

## Deploy

Den Inhalt dieses Ordners direkt als Cloudflare-Pages-Projekt veröffentlichen. Es wird kein Build-System und kein JavaScript benötigt.

## Dateien

- `index.html` - vollständige SEO-/Eventseite
- `style.css` - responsive Gestaltung
- `robots.txt` - Crawler-Regeln
- `sitemap.xml` - Sitemap für die kanonische Event-URL
- `assets/hero-darts.webp` - dekoratives Flyer-Motiv
- `assets/og-dartturnier.webp` - Social Preview 1200×630
- `assets/flyer.webp` - komprimierte Flyer-Referenz
